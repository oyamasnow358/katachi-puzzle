# かたち パズル（MieeL）

かたちを みる・まわす・くみあわせる ちから（図形・空間認知）を そだてる パズル アプリです（特別支援教育向け・iPad / iPhone）。

## できること
- 🔷 **タングラム**：ピースを ゆびで うごかし、タッチで 90ど まわして シルエットに はめる。さんかく・ふね・ダイヤ（2こ）→ さかな・いえ・き（3〜4こ）→ しかく・おおきな さかな（7こ）。なかの せん（ヒント）は じどう／いつも／なし
- 🔲 **おてほん うつし**：3×3 → 4×4 → さんかくの むきまで、おてほんと おなじ もようを つくる。ちがう ますは あかい わくで おしえる
- 🔄 **まわすと どれ？**：みぎに まわす・さかさま・かがみに うつす と どう なるか（うらがえしの かたちと くらべる）
- ⭐ **かたち はめ**：おなじ かたちの あなに いれる（しかく・ながしかく・ひしがた・まる・だえん… の みわけ）
- ⭐ と きろく（子どもごと）
- **A4 プリント**：タングラム（シルエット ＋ きりとる ピース の 2まい、おなじ おおきさ）・おてほん うつし・まわすと どれ？（こたえ つきも）
- 🏠 ボタンで いつでも さいしょへ（パズル ちゅうは ながおし）

きろくは この たんまつの なかだけに ほぞん し、インターネットには おくりません。
